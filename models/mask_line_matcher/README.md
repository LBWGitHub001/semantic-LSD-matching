## 一、核心思想与 6 通道几何场设计

### 1. 传统标量掩膜的致命缺陷
若将图像中检测出的 $N$ 条线段分别赋予标量编号（如第 1 号线填 1，第 250 号线填 250）并作为单通道特征输入 CNN，会导致两个灾难性问题：
1. **序数偏置 (Ordinal Bias)**：CNN 卷积核为线性加权，会误将标量离散 ID 当成空间度量，误认为“线 1”与“线 2”极其临近，而与“线 250”极其遥远；
2. **置换等变性失效**：跨视角线段检测器的索引排序是随机的。交换任意两条线的编号会导致输入矩阵数值剧烈跳变，CNN 无法学到任何稳健特征。

### 2. 6通道连续几何场 (EDT + AFM)
为彻底破除离散序数偏置，模型设计了纯几何连续场作为输入：
```text
输入张量 (B, 6, H, W):
├── 通道 0..2: 标准归一化 RGB 图像 (3 通道)
├── 通道 3:    欧氏距离变换场 (EDT, 1 通道)
└── 通道 4..5: 二倍角吸引朝向场 (AFM, 2 通道)
```

1. **欧氏距离变换场 (EDT)**：
   每个像素的值等于其到场景中**最近线段**的物理欧氏距离：
   $$\text{EDT}(p) = \min_{l_k \in \mathcal{L}} \text{dist}(p, l_k)$$
   随后经高斯核截断归一化至 $[0, 1]$，数值纯净反映线段临近度。
2. **二倍角吸引朝向场 (AFM)**：
   线段是没有起始端点方向的无向几何基元（$\theta$ 与 $\theta + \pi$ 表示同一条几何线）。直接编码 $\theta$ 会在 $0$ 与 $\pi$ 产生不连续相位截断。因此采用**二倍角编码**：
   $$\text{AFM}(p) = \left[ \cos(2\theta(p)), \sin(2\theta(p)) \right] \in [-1, 1]^2$$
   - 无论线段正向还是反向，二倍角三角函数值恒定，消除起止二义性。

## 二、网络架构与 255x255 规范矩阵

1. **骨干网络**：多阶段残差卷积，提取 6 通道稠密局部几何-外观特征；
2. **线段掩膜引导池化**：为每条线段生成其几何膨胀骨架掩膜，在特征图上提取线段 Token；
3. **固定规范矩阵输出 $(B, 255, 255)$**：
   - 为满足工业级批量推理部署，网络输出维度固定为 $(255, 255)$；
   - 前 $N_0 \times N_1$ 有效子区域输出匹配概率；超出范围的非激活填充区域在数学上严格置零 ($0.0$)。

## 三、损失函数详解

本模型在 [`loss.py`](file:///home/lbw/Project/semantic-LSD-matching/models/mask_line_matcher/loss.py) 中提供了两种互补的损失函数：

### 1. LineMatchingLoss (Sinkhorn 对数似然损失)
适用于线段通过 Log-Sinkhorn 算法输出双随机分配矩阵的场景：
$$\mathcal{L}_{\text{NLL}} = -\frac{1}{M} \sum_{k=0}^{M-1} \log P_{k, k}$$
- 强力拉大对角线真值匹配概率；
- 具有极快的梯度回传收敛速度。

### 2. MaskedMatrixLoss (双重混合监督损失: NLL + Masked BCE)
针对 $(B, 255, 255)$ 规范矩阵设计的专用混合监督损失：
$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{NLL}} + \lambda_{\text{BCE}} \cdot \mathcal{L}_{\text{BCE}}$$

1. **Sinkhorn NLL**：保证有效匹配对在一对一分配上的互斥性与高置信度；
2. **Masked BCE**：在有效的 $(N_0 \times N_1)$ 子矩阵上进行二值交叉熵监督，精确压制所有非匹配背景网格的响应；超出 $N_0, N_1$ 的填充区域不计入 Loss，杜绝虚假梯度干扰。

## 四、严格置换等变性证明与单元测试

`MaskLineFeatMatchNet` 在理论和实现上均满足严格的**置换等变性（Permutation Equivariance）**：
$$M(P_{\pi_0} \mathcal{L}_0, P_{\pi_1} \mathcal{L}_1) = P_{\pi_0} M(\mathcal{L}_0, \mathcal{L}_1) P_{\pi_1}^T$$

您可以通过运行单元测试进行机器精度核验：
```bash
python tools/run_unit_tests.py
```
* 实测置换前后输出矩阵的最大绝对误差 $< 2.98 \times 10^{-8}$，严格达到机器浮点精度极限。
